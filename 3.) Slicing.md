# 1.) Slicing ✂️

## Overview

**Slicing** is a technique used in Python to extract a **portion (subsequence)** of a sequence.
It works on all **sequence types**, most commonly:

* Strings (`str`)
* Lists (`list`)
* Tuples (`tuple`)

Slicing allows you to access ranges of elements **without loops** and without modifying the original sequence.

---

## Basic Syntax

```python
sequence[start : end : step]
```

| Part    | Meaning                         |
| ------- | ------------------------------- |
| `start` | Index to begin from (inclusive) |
| `end`   | Index to stop at (exclusive)    |
| `step`  | How many elements to skip       |

All three are **optional**.

---

## Simple Slicing Examples

### Strings

```python
text = "Python"
print(text[0:4])   # 'Pyth'
print(text[2:])    # 'thon'
print(text[:3])    # 'Pyt'
```

### Lists

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])   # [1, 2, 3]
```

---

## Why the End Index Is Excluded

Python slicing follows the rule:

> **start is inclusive, end is exclusive**

This makes slicing predictable and composable:

```python
nums = [0, 1, 2, 3]
print(nums[0:2])  # [0, 1]
print(nums[2:4])  # [2, 3]
```

---

## Using Step

The `step` value controls how elements are skipped.

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[::2])   # [0, 2, 4]
print(nums[1::2])  # [1, 3, 5]
```

---

## Negative Indexing

Negative indices count from the **end** of the sequence.

```python
text = "Python"
print(text[-1])    # 'n'
print(text[-4:-1]) # 'tho'
```

Index mapping:

```
 P  y  t  h  o  n
 0  1  2  3  4  5
-6 -5 -4 -3 -2 -1
```

---

## Reversing a Sequence

A very common slicing trick:

```python
text = "Python"
print(text[::-1])  # 'nohtyP'
```

How it works:

* No start → begin at end
* No end → go to beginning
* Step `-1` → move backwards

---

## Slicing Does NOT Modify Original Data

Slicing always returns a **new sequence**.

```python
nums = [1, 2, 3, 4]
part = nums[:2]
part[0] = 100

print(nums)  # [1, 2, 3, 4]
```

---

## Slicing vs Indexing

| Feature    | Indexing               | Slicing                   |
| ---------- | ---------------------- | ------------------------- |
| Returns    | Single element         | Subsequence               |
| Syntax     | `a[i]`                 | `a[i:j]`                  |
| Error risk | Can raise `IndexError` | Safe even if out of range |

```python
nums = [1, 2, 3]
print(nums[10:])  # [] (no error)
```

---

## Common Use Cases

* Extracting substrings
* Copying lists (`new_list = old_list[:]`)
* Skipping elements
* Reversing sequences
* Cleaning or trimming data

---

## Important Confusion Points 🚨

* **End index is excluded** — this is intentional, not a bug.
* Slicing never throws `IndexError`.
* Negative indices count from the end.
* `sequence[:]` creates a **shallow copy**.
* Step can be negative.
* Slicing works only on **sequence types**, not dictionaries or sets.

---

## Mental Model

Think of slicing as:

> "Give me elements starting at `start`, keep going **until just before `end`**, moving `step` at a time."

---

## Summary Cheat Sheet

```python
a[start:end]        # basic slice
a[:end]             # from start
a[start:]           # till end
a[:]                # full copy
a[::step]           # skip elements
a[::-1]             # reverse
```

---

## Final Takeaway

Slicing is one of Python’s most powerful and elegant features.
Once mastered, it eliminates many loops and makes code **cleaner, faster, and more readable**.

Master slicing early — it appears everywhere in real Python code.
