## What Are They?

`*args` and `**kwargs` allow functions to accept **variable number of arguments**.

### Quick Overview

```python
def function(normal_arg, *args, **kwargs):
    pass

function(1, 2, 3, name="Alice", age=25)
```

- `normal_arg` = 1
- `*args` = (2, 3) → **tuple** of extra positional arguments
- `**kwargs` = {'name': 'Alice', 'age': 25} → **dict** of extra keyword arguments

### Important Notes
- The **names** `args` and `kwargs` are just **conventions** (you can use `*numbers`, `**options`)
- The **`*` and `**`** symbols are what matter
- Order matters: `def func(regular, *args, **kwargs)`

---

## *args - Variable Positional Arguments

Collects extra positional arguments into a **tuple**.

### Basic Example

```python
def add_numbers(*args):
    print(type(args))  # <class 'tuple'>
    total = 0
    for num in args:
        total += num
    return total

print(add_numbers(1, 2, 3))        # 6
print(add_numbers(10, 20, 30, 40)) # 100
print(add_numbers(5))              # 5
print(add_numbers())               # 0 (empty tuple)
```

### With Regular Parameters

```python
def greet(greeting, *names):
    for name in names:
        print(f"{greeting}, {name}!")

greet("Hello", "Alice", "Bob", "Charlie")
# Output:
# Hello, Alice!
# Hello, Bob!
# Hello, Charlie!
```

### Real-World Example

```python
def create_user(username, *roles):
    user = {"username": username, "roles": []}
    for role in roles:
        user["roles"].append(role)
    return user

user1 = create_user("alice", "admin", "editor")
user2 = create_user("bob", "viewer")

print(user1)  # {'username': 'alice', 'roles': ['admin', 'editor']}
print(user2)  # {'username': 'bob', 'roles': ['viewer']}
```

### Key Points
- `*args` captures all **remaining positional** arguments
- Results in a **tuple** (immutable)
- Can iterate over it like any tuple
- Empty if no extra arguments provided

---

## **kwargs - Variable Keyword Arguments

Collects extra keyword arguments into a **dictionary**.

### Basic Example

```python
def print_info(**kwargs):
    print(type(kwargs))  # <class 'dict'>
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=25, city="NYC")
# Output:
# name: Alice
# age: 25
# city: NYC
```

### With Regular Parameters

```python
def create_profile(username, email, **details):
    profile = {
        "username": username,
        "email": email,
        "details": details
    }
    return profile

profile = create_profile(
    "alice",
    "alice@example.com",
    age=25,
    country="USA",
    hobby="coding"
)

print(profile)
# {
#   'username': 'alice',
#   'email': 'alice@example.com',
#   'details': {'age': 25, 'country': 'USA', 'hobby': 'coding'}
# }
```

### Real-World Example: Database Query

```python
def find_users(**filters):
    query = "SELECT * FROM users WHERE "
    conditions = []
    
    for key, value in filters.items():
        conditions.append(f"{key} = '{value}'")
    
    query += " AND ".join(conditions)
    return query

print(find_users(city="NYC", age=25))
# SELECT * FROM users WHERE city = 'NYC' AND age = '25'

print(find_users(country="USA"))
# SELECT * FROM users WHERE country = 'USA'
```

### Key Points
- `**kwargs` captures all **remaining keyword** arguments
- Results in a **dictionary**
- Keys are parameter names (strings)
- Empty dict if no extra arguments provided

## Using Both Together

You can combine regular parameters, `*args`, and `**kwargs`.

### Order Matters!

```python
def function(a, b, *args, **kwargs):
    print(f"a = {a}")
    print(f"b = {b}")
    print(f"args = {args}")
    print(f"kwargs = {kwargs}")

function(1, 2, 3, 4, 5, x=10, y=20)
```

**Output:**
```
a = 1
b = 2
args = (3, 4, 5)
kwargs = {'x': 10, 'y': 20}
```

### Correct Order

```python
# ✅ CORRECT ORDER
def func(pos_arg, *args, default_arg=None, **kwargs):
    pass

# ❌ WRONG ORDER - SyntaxError
def func(*args, pos_arg, **kwargs):
    pass
```

**Rule**: `regular_params, *args, keyword_only_params, **kwargs`

### Full Example

```python
def process_order(order_id, *items, discount=0, **customer_info):
    print(f"Order ID: {order_id}")
    print(f"Items: {items}")
    print(f"Discount: {discount}%")
    print(f"Customer: {customer_info}")

process_order(
    12345,
    "Laptop", "Mouse", "Keyboard",
    discount=10,
    name="Alice",
    email="alice@example.com"
)
```

**Output:**
```
Order ID: 12345
Items: ('Laptop', 'Mouse', 'Keyboard')
Discount: 10%
Customer: {'name': 'Alice', 'email': 'alice@example.com'}
```

## Unpacking with * and **

The `*` and `**` operators also work in **reverse** - unpacking collections into function arguments.

### Unpacking Lists/Tuples with *

```python
def add(a, b, c):
    return a + b + c

numbers = [1, 2, 3]
result = add(*numbers)  # Unpacks to: add(1, 2, 3)
print(result)  # 6

# Without unpacking:
# add(numbers)  # ❌ TypeError: missing 2 required positional arguments
```

### Unpacking Dictionaries with **

```python
def create_user(name, age, city):
    print(f"{name}, {age}, from {city}")

user_data = {"name": "Alice", "age": 25, "city": "NYC"}
create_user(**user_data)  # Unpacks to: create_user(name="Alice", age=25, city="NYC")

# Output: Alice, 25, from NYC
```

### Combining Both

```python
def make_pizza(size, *toppings, **details):
    print(f"Size: {size}")
    print(f"Toppings: {toppings}")
    print(f"Details: {details}")

# Unpacking multiple sources
size = "Large"
toppings = ["cheese", "pepperoni"]
details = {"crust": "thin", "delivery": True}

make_pizza(size, *toppings, **details)
```

**Output:**
```
Size: Large
Toppings: ('cheese', 'pepperoni')
Details: {'crust': 'thin', 'delivery': True}
```

### Merging Collections

```python
# Merging lists
list1 = [1, 2, 3]
list2 = [4, 5, 6]
merged = [*list1, *list2]  # [1, 2, 3, 4, 5, 6]

# Merging dictionaries
dict1 = {"a": 1, "b": 2}
dict2 = {"c": 3, "d": 4}
merged_dict = {**dict1, **dict2}  # {'a': 1, 'b': 2, 'c': 3, 'd': 4}

# Later values override earlier ones
dict3 = {"a": 100}
merged_override = {**dict1, **dict3}  # {'a': 100, 'b': 2}
```

## Common Use Cases

### 1. Wrapper Functions / Decorators

```python
def log_function_call(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        result = func(*args, **kwargs)
        print(f"Finished {func.__name__}")
        return result
    return wrapper

@log_function_call
def add(a, b):
    return a + b

add(5, 3)
```

**Output:**
```
Calling add
Finished add
```

### 2. Extending Parent Class Methods

```python
class Parent:
    def __init__(self, name):
        self.name = name

class Child(Parent):
    def __init__(self, name, *args, **kwargs):
        super().__init__(name)
        self.extra_args = args
        self.extra_kwargs = kwargs

child = Child("Alice", 25, 30, city="NYC", country="USA")
print(child.name)         # Alice
print(child.extra_args)   # (25, 30)
print(child.extra_kwargs) # {'city': 'NYC', 'country': 'USA'}
```

### 3. Flexible API Functions

```python
def send_email(to, subject, body, **options):
    email = {
        "to": to,
        "subject": subject,
        "body": body
    }
    
    # Optional parameters
    if "cc" in options:
        email["cc"] = options["cc"]
    if "attachments" in options:
        email["attachments"] = options["attachments"]
    if "priority" in options:
        email["priority"] = options["priority"]
    
    return email

# Different usage scenarios
send_email("bob@example.com", "Hi", "Hello Bob")
send_email("alice@example.com", "Report", "See attached", 
           attachments=["report.pdf"], priority="high")
```

### 4. Variadic Functions (like print)

```python
# Python's print function uses *args
print("Hello", "World", 123, True, sep=" | ")
# Hello | World | 123 | True

def my_print(*args, sep=" ", end="\n"):
    output = sep.join(str(arg) for arg in args)
    print(output, end=end)

my_print(1, 2, 3, 4, sep=" -> ")  # 1 -> 2 -> 3 -> 4
```

## Interview Questions

### Q1: What's the difference between `*args` and `**kwargs`?

**Answer:**
- `*args` collects extra **positional** arguments into a **tuple**
- `**kwargs` collects extra **keyword** arguments into a **dictionary**

```python
def example(*args, **kwargs):
    print(f"args (tuple): {args}")
    print(f"kwargs (dict): {kwargs}")

example(1, 2, 3, name="Alice", age=25)
# args (tuple): (1, 2, 3)
# kwargs (dict): {'name': 'Alice', 'age': 25}
```

---

### Q2: Can you use any name instead of args and kwargs?

**Answer:** Yes! The `*` and `**` symbols matter, not the names.

```python
def func(*numbers, **options):  # ✅ Valid
    pass

def func(*items, **config):     # ✅ Valid
    pass
```

However, `args` and `kwargs` are **strong conventions** - stick to them for readability.

---

### Q3: What's the correct order of parameters?

**Answer:**
```python
def function(
    positional,           # Required positional
    *args,                # Variable positional
    keyword_only,         # Keyword-only (after *args)
    default=value,        # Keyword with default
    **kwargs              # Variable keyword
):
    pass
```

**Example:**
```python
def process(name, *scores, grade="A", **details):
    pass

process("Alice", 90, 95, grade="A+", city="NYC")
```

---

### Q4: How do you unpack a list into function arguments?

**Answer:** Use `*` operator

```python
def add(a, b, c):
    return a + b + c

numbers = [1, 2, 3]
result = add(*numbers)  # Unpacks to add(1, 2, 3)
```

---

### Q5: Can you use *args in function call without defining it?

**Answer:** Yes! `*` can unpack any iterable when **calling** a function.

```python
def greet(first, last):
    print(f"Hello {first} {last}")

name = ["Alice", "Smith"]
greet(*name)  # Unpacks to greet("Alice", "Smith")
```

---

### Q6: What happens if you pass both args and kwargs to a function?

**Answer:** 
```python
def func(a, b, *args, **kwargs):
    print(a, b, args, kwargs)

func(1, 2, 3, 4, x=10, y=20)
# Output: 1 2 (3, 4) {'x': 10, 'y': 20}
```

Positional arguments fill regular params first, then `*args`. Keyword arguments go to `**kwargs`.

---

### Q7: How to pass variable arguments to another function?

**Answer:**
```python
def outer_function(*args, **kwargs):
    # Pass everything to another function
    inner_function(*args, **kwargs)

def inner_function(a, b, c=None):
    print(a, b, c)

outer_function(1, 2, c=3)  # 1 2 3
```

---

### Q8: Can you modify *args or **kwargs inside function?

**Answer:**
- `*args` is a **tuple** (immutable) - cannot modify
- `**kwargs` is a **dict** (mutable) - can modify

```python
def modify(*args, **kwargs):
    # args[0] = 100  # ❌ TypeError: tuple doesn't support item assignment
    
    kwargs["new_key"] = "new_value"  # ✅ Works
    print(kwargs)

modify(1, 2, x=10)  # {'x': 10, 'new_key': 'new_value'}
```

**Workaround for args:**
```python
def modify(*args):
    args = list(args)  # Convert to list
    args[0] = 100
    print(args)
```

### Q9: Real-world use case in decorators?

**Answer:**
```python
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)  # Pass all arguments
        end = time.time()
        print(f"{func.__name__} took {end - start:.4f} seconds")
        return result
    return wrapper

@timer
def slow_function(n):
    time.sleep(n)
    return "Done"

slow_function(2)  # slow_function took 2.0001 seconds
```

### Q10: Difference between * in definition vs call?

**Answer:**

**In definition**: Packing (collecting arguments)
```python
def func(*args):  # Packs into tuple
    print(args)

func(1, 2, 3)  # (1, 2, 3)
```

**In call**: Unpacking (spreading arguments)
```python
def func(a, b, c):
    print(a, b, c)

numbers = [1, 2, 3]
func(*numbers)  # Unpacks to func(1, 2, 3)
```

## Common Mistakes ⚠️

### Mistake 1: Wrong Order
```python
# ❌ WRONG
def func(**kwargs, *args):
    pass

# ✅ CORRECT
def func(*args, **kwargs):
    pass
```

### Mistake 2: Forgetting to Unpack
```python
def add(a, b):
    return a + b

numbers = [1, 2]
add(numbers)    # ❌ TypeError
add(*numbers)   # ✅ Correct
```

### Mistake 3: Modifying Tuple Args
```python
def func(*args):
    args[0] = 100  # ❌ TypeError: tuple is immutable
```

### Mistake 4: Keyword After **kwargs
```python
# ❌ WRONG - SyntaxError
def func(**kwargs, special):
    pass

# ✅ CORRECT
def func(special, **kwargs):
    pass
```
